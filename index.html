Servidor local necessário

Este WebGIS precisa ser executado em um servidor local para carregar arquivos GeoJSON.

Navegadores bloqueiam o carregamento de arquivos locais por segurança quando o projeto é aberto diretamente pelo explorador de arquivos.

Abrir http://localhost:3000

Como iniciar o WebGIS

1
Executar start_server.bat

Duplo clique no arquivo na pasta do projeto (Windows).

2
Node.js

Na pasta do projeto, no terminal:

npm install && npm start
3
Python

Na pasta do projeto, no terminal:

python server.py

Depois acesse http://localhost:3000 no navegador.
